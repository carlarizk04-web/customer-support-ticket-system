# Customer Support Ticket Management System

A console-based customer support ticket management system developed in C++.

## Features

* Create new support tickets
* View all tickets
* View individual ticket details
* Search tickets by customer or issue
* Update ticket status
* Change ticket priority
* Assign and reassign support agents
* Delete tickets
* View support statistics
* Save and load ticket data using file handling
* Input validation and error handling

## Technologies

* C++
* C++ Standard Library
* File Handling
* Object-Oriented Programming Concepts
* Data Structures

## Ticket Information

Each ticket contains:

* Ticket ID
* Customer name
* Customer email
* Issue description
* Priority
* Status
* Assigned support agent

## How to Run

1. Clone or download the repository.
2. Open `customer_support_system.cpp` in a C++ compiler.
3. Compile and run the program.
4. The system will automatically create `tickets.txt` to store ticket data.

## Project Purpose

This project was created to practice C++ programming concepts by developing a practical customer support management application.
