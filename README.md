# 🎫 Customer Support Ticket Management System — C++

A **console-based Customer Support Ticket Management System built in C++**, designed to simulate the workflow of a technical support environment.

The application allows support agents to create, search, update, and track customer support tickets through a structured menu-driven interface. The project focuses on applying C++ programming fundamentals to a practical, real-world support scenario.

## 🚀 Key Features

* 🎫 Create new customer support tickets
* 🔎 Search for existing tickets
* ✏️ Update ticket information
* 📋 View and track customer tickets
* 📌 Manage ticket status
* 👤 Store customer-related information
* ⚠️ Validate user input
* 🛡️ Handle invalid entries and incorrect selections
* 🔄 Continue managing multiple tickets within the same session
* 🖥️ Simple and user-friendly console interface

## 🔄 Ticket Workflow

The system follows a simple support-ticket workflow:

```text
Customer Issue
      ↓
Create Ticket
      ↓
Ticket Stored
      ↓
Search / View Ticket
      ↓
Update Ticket
      ↓
Track Status
      ↓
Resolve / Close Ticket
```

This structure reflects the basic lifecycle of a customer support case, from initial issue reporting to resolution.

## 💻 Example

